## Régression logistique

Pour tirer une classification d'une régression logistique en R, il faut faire une étape supplémentaire après la régression proprement dite : il faut convertir les probabilités en prédictions à l'aide du choix d'un *seuil*.

Commençons par charger les données :

```{r}

# Chargement des données et traitement de la colonne d'intérêt

# Choisir le fichier des cartes de crédit
mydata <- read.table(file.choose(), header=TRUE, sep=";", 
                     na.strings="NA", dec=".", strip.white=TRUE)

mydata$Default.Next.Month = factor(mydata$Default.Next.Month)
```

On fait la régression à l'aide de `glm` :

```{r}
model <- glm(Default.Next.Month ~ EDUCATION + SEX + MARRIAGE + AGE,
             data = mydata, family = binomial)
summary(model)
```

Ensuite on fixe un seuil (*threshold* ou *cutoff* dans la littérature) et on calcule les prédictions de classes à l'aide de ce seuil :

```{r}

threshold = 0.25
predictions <- predict(model, type = "response")
predicted_classes <- factor(ifelse(predictions > threshold, 1, 0), levels=c(0,1))
```

On compare avec les valeurs présentes dans les données :

```{r}

library(caret)

confusionMatrix(predicted_classes, mydata$Default.Next.Month)
```

**Note :** Ici j'ai simplifié le processus, d'habitude on sépare les données en un jeu d'entraînement et un jeu de test.

```{r}
library(ROCR)
pred <- prediction(predictions, mydata$Default.Next.Month)
perf <- performance(pred, "tpr", "fpr")
plot(perf, colorize = TRUE)
```

Idéalement, la courbe ROC devrait partir de (0,0), monter presque verticalement jusqu'à la hauteur 1, puis continuer presqu'horizontalement jusque (1,1). Le seuil optimal se trouve quelque part près du point (0,1) : on veut très peu de faux positifs (x proche de 0) et beaucoup de vrais positifs (y proche de 1).

Ce n'est pas du tout le cas ici, la courbe est presque plate, donc on sait que le taux d'erreur sera important quel que soit le choix de seuil.

On peut choisir sur la courbe ROC *le point le plus proche de (0,1)* de la façon suivante :

```{r}
opt.cut <- function(perf, pred){
  cut.ind <- mapply(FUN=function(x, y, p){
    d <- (x - 0)^2 + (y-1)^2
    ind <- which(d == min(d))
    c(sensitivity = y[[ind]], specificity = 1-x[[ind]], cutoff = p[[ind]])
  }, perf@x.values, perf@y.values, pred@cutoffs)
}
optimal <- opt.cut(perf, pred)
print(optimal)
```

On teste cette valeur :

```{r}
threshold = optimal["cutoff",1]
predictions <- predict(model, type = "response")
predicted_classes <- factor(ifelse(predictions > threshold, 1, 0), levels=c(0,1))
confusionMatrix(predicted_classes, mydata$Default.Next.Month)
```

Comme on le voit, ce point ne minimise pas forcément le taux d'erreur global. Il fait un compromis entre taux de faux positifs bas et taux de vrais positifs haut.

La **sensibilité** est la capacité à identifier correctement les vrais positifs. Elle se calcule comme le quotient `(vrais positifs) / (vrais positifs + faux négatifs)`.

La **spécificité** est la capacité à identifier correctement les vrais négatifs. Elle se calcule comme le quotient `(vrais négatifs) / (vrais négatifs + faux positifs)`.

Le **taux de faux positifs** est `1 - spécificité`.
